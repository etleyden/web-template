# Ethan's Web Template

This repository serves as a jumping point for building a web application. When it's finished, the tech stack will already be configured for you, all you'll have to do it run a few setup scripts, and start with developing your application. 

# Setup

1. Run `npm install`
2. Run `docker-compose up`

If that doesn't work, create an issue and let me know.


[Using a repo as a template](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository)
